## 🚀 Projetos em destaque

### ⚙️ Automação com Make e Inteligência Artificial

Projeto acadêmico de automação e integração entre ferramentas. A partir de um formulário de entrada, o fluxo processa os dados com IA e gera e envia por e-mail um documento personalizado. O cenário usa um **Router** com filtro e uma **rota alternativa (fallback)** que envia um e-mail quando a condição principal não é atendida.

- **Tecnologias:** Make, Google Sheets, Gemini API, JSON, Google Docs, Gmail
- **Conceitos aplicados:** gatilho de monitoramento de novas linhas, roteamento condicional, tratamento de rota alternativa, parse de JSON e geração de documento a partir de template

```text
Formulário ─► Google Sheets ─► Router ─┬─► (filtro) Gemini ─► JSON ─► Google Docs ─► Gmail
                                       └─► (fallback) Gmail
```
